نکات کلیدیHighlights

  • توسعه یک اپلیکیشن وب پیشرو (PWA) تعاملی با چندین بخش و قابلیت مستقل، قابل نصب روی دستگاه کاربر و قابل استفاده مانند یک اپلیکیشن بومی.
  • پیاده‌سازی احراز هویت کاربر، مدیریت پروفایل، نامه‌ها، خاطرات، موسیقی، رویدادها، شمارنده‌های معکوس و محتوای تعاملی.
  • ایجاد تعامل‌های پویا سمت کاربر، استفاده از Local Storage، ارسال درخواست‌های API و به‌روزرسانی رابط کاربری با JavaScript.
  • توسعه بخش بک‌اند و ربات تلگرام با Python و اتصال آن‌ها به اپلیکیشن از طریق API و داده‌های JSON.
  • افزودن قابلیت‌های هوش مصنوعی (AI) شامل چت‌بات و سیستم پیشنهاد هوشمند به اپلیکیشن.
  • Developed an interactive Progressive Web App (PWA) with multiple independent sections and features, installable on the user's device and usable like a native application.
  • Implemented user authentication, profile management, letters, memories, music, events, countdowns, and interactive content.
  • Built dynamic client-side interactions, local storage usage, API requests, and UI updates with JavaScript.
  • Developed the backend and Telegram Bot with Python, connecting them to the application through APIs and JSON data.
  • Added artificial intelligence (AI) capabilities to the application, including a chatbot and smart recommendations.

  • Implemented the Mediator design pattern to decouple game logic, UI screens, and tile rendering.
  • Engineered kingdom economics, resource management, troop recruitment, and dynamic White Walker invasions.
  • Built custom battle logging and real-time combat replay mechanisms.
